# Jarvis Android installieren (Galaxy A55)

1. **APK herunterladen** von der GitHub-Release-Seite (Datei `Jarvis.apk`).
2. In **Chrome** die Datei öffnen bzw. aus den Downloads tippen.
3. Falls nötig: **Unbekannte Apps installieren** erlauben  
   (Chrome → Einstellungen → Apps → Chrome → Unbekannte Apps installieren → Erlauben).
4. Bei **Play Protect**-Warnung: „Trotzdem installieren“ / Details → trotzdem installieren  
   (Debug-Signatur, nicht aus dem Play Store).
5. Jarvis öffnen → Mikrofon-, Standort- und ggf. Kamerarechte erlauben.
6. Name/Stimme wählen, Gemini-API-Schlüssel eintragen (wie in der PWA).

Deinstallieren: App-Info → Deinstallieren.
